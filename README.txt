=========================================
 設備の記録帳（facility-logbook）
=========================================

設備の「運転記録」と「点検チェックリスト」を1つにまとめた、社内LAN向けのWebアプリです。
詳しい使い方は、取扱説明書を見てください。

　　docs\manual\取扱説明書.pdf


【はじめて使うとき】
　1. Python 3.11 以降を入れる（https://www.python.org/ 「Add Python to PATH」にチェック）
　2. 「初回セットアップ.bat」をダブルクリック（インターネットが必要です）

【起動と停止】
　・起動：「起動.bat」をダブルクリック → ブラウザで http://127.0.0.1:6060 を開く
　・停止：黒い画面を閉じる、または Ctrl+C

【ほかのPC・タブレットから】
　・ブラウザで http://<サーバーPCのIPアドレス>:6060 を開く（取扱説明書 2章）

【新しい版に入れ替えるとき】
　1. 新しい版を別の名前のフォルダに展開する（まだ「起動.bat」は開かない）
　2. 新しいフォルダの「データ引き継ぎ.bat」に、古い版のフォルダをドラッグして重ねる
　3. 「初回セットアップ.bat」→「起動.bat」の順に実行する（取扱説明書 7-4）
