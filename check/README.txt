設備運転 点検チェックリストアプリ

【初回】初回セットアップ.bat をダブルクリック
【起動】起動.bat をダブルクリック → ブラウザで http://127.0.0.1:5001 を開く

【設備の追加】
 equipments\<好きな名前>\ フォルダを作り、以下を置く:
   - equipment.json … 表示名・順番（key/name/order）
   - checklist.csv  … 点検項目（区分,点検内容,種別,単位,下限,上限,備考）
   - form.pdf       … 規定様式PDF（平らなPDF）
   - mapping.json   … PDFへの書き込み座標
 ※座標設定が分からない場合は様式PDFとCSVを渡して依頼してください。

【点検】設備タブを選び、チェック/数値を入力 → 「点検を保存」
【過去結果】「過去の点検結果」タブで閲覧・PDF出力
